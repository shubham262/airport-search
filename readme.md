## 🚀 Getting Started

Follow these instructions to set up the project on your local machine for development and testing.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed on your system.

### 1. Clone the Repository

First, clone the repository to your local machine:

```bash
git clone <your-repository-url>
cd <your-project-folder>

```

### 2. Frontend Setup

Open a terminal window and navigate to the frontend directory to install dependencies and start the development server:

```bash
cd frontend
npm install
npm run dev

```

### 3. Backend Setup

Open a **new** terminal window and navigate to the backend directory:

```bash
cd backend

```

#### Environment Variables

Before starting the backend server, you need to set up your environment variables:

1. Create a new file named `.env` in the `backend` directory.
2. Open the `.env.example` file provided in the folder.
3. Copy the contents of `.env.example` into your new `.env` file and fill in the required values (like your database connection string, API keys, etc.).

#### Install and Run

Once your `.env` file is ready, install the dependencies and start the backend development server:

```bash
npm install
npm run dev

```
